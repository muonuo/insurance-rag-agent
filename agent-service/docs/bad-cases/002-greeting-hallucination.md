# 002: 个性化问候编造称呼和历史

- **发现时间**：2026-11-17
- **根因分类**：幻觉
- **严重级别**：中（不涉及金钱/条款错误，但直接损害信任）
- **状态**：已修复（提示词加固 + 回归测试）

## 1. 现象

用户只发了一句「你好」，AI 回复：

> 王先生，好久不见，最近还好吧？你之前说想再看看医疗险，现在家里都配齐了吗？

问题：
- 用户不姓王（账号 `monuo / 陌陌`）
- 用户从没说过"想再看看医疗险"
- 这是全新会话，没有"之前"

## 2. 定位过程与证据

**Step 1 · 查画像**（个性化问候的唯一事实来源）

```
{'age': 32, 'family': '已婚', 'budget': '每年15万元',
 'existing_coverage': None, 'health_notes': None,
 'preferences': '无特殊要求', 'notes': None}
```

画像结构里**没有姓名字段**，也没有任何关于"医疗险"的记录。

**Step 2 · 查账号**

```
users: (37, 'monuo', '陌陌')
```

不是"王"。

**Step 3 · 查会话消息**

会话只有 2 条：

```
[用户]: 你好
[AI]:   王先生，好久不见…
```

历史里**没有任何一处提到过"王"或"医疗险"**。

**结论**：模型在画像/账号/历史三方都没有依据的情况下，凭空补了一个姓氏和一段虚构历史。

## 3. 根因

**问候提示词约束不足**。原提示词只要求"像熟人打招呼、不要复述画像内容"，
本意是让语气自然，但模型为了"像熟人"会自行填充细节——
在没有禁止性约束时，补全缺失信息是语言模型的默认行为。

## 4. 修复

**提示词层**（`app/agents/intent_router.py` 的 `GREETING_SYSTEM_PROMPT`）：

```
1. 只能使用给定画像中的事实。严禁编造画像里没有的信息，尤其是：
   - 不要编造称呼或姓氏（不要叫"王先生/李女士"等，统一用"您好"）；
   - 不要编造"你之前说过…""上次提到…"这类历史，除非最近对话里确实出现过。
```

## 5. 验证

- 删除画像后说「你好」→ 走固定话术（无画像不触发个性化问候）✅
- 新增 3 个提示词回归测试（`tests/test_intent_router.py::TestGreetingPromptGuard`），
  任何人删掉这些约束测试立刻失败
- 画像重新建立后可复测：问候应只引用画像中真实存在的字段（年龄/家庭/预算/偏好）

## 6. 沉淀

**原则：个性化生成必须显式约束"只能使用给定事实"，并点名禁止最容易发生幻觉的几类内容**
（称呼、历史、数字）。泛泛地说"不要复述"不够——模型会理解成"不要照读"，而不是"不要编造"。

**可复用检查清单**：任何"个性化/上下文引用"类提示词，都要回答三个问题：
1. 允许使用的事实来源有哪些？（画像 / 最近对话 / 工具结果）
2. 哪些信息最容易被编造？（称呼、过往承诺、具体数字）
3. 有没有测试防止约束被后续修改删掉？
